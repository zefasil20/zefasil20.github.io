# Zefasil Mulu — Portfolio

A responsive, static portfolio for GitHub Pages built with HTML, CSS, and vanilla JavaScript.

## Included
- Modern Developer Workspace visual direction
- Responsive navigation for desktop and mobile
- Dark/light theme toggle with saved preference and system-theme default
- Project cards preserving the original academic and team project descriptions
- About, toolkit, opportunity, and contact sections
- Accessibility basics: skip link, semantic sections, visible focus, reduced-motion support
- Basic SEO and social metadata

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

For a local development server, you can use the VS Code Live Server extension or run Python from the project root:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Extract the ZIP.
2. Review the site locally and confirm all links and content.
3. Copy `index.html`, `css/`, and `js/` into the root of your `zefasil20.github.io` repository.
4. Commit and push to the repository's published branch.
5. Wait for GitHub Pages to deploy, then test the live site on desktop and mobile.

## Before publishing
- Confirm the email and LinkedIn URLs are current.
- Add repository/demo links only for the correct public projects.
- Replace the CSS-built project illustrations with real screenshots when available.
- Verify that all listed technologies reflect your current experience.
- If adding an X profile link, use your actual public profile URL.
